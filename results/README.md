# `results/` — per-patient score tables

Every CSV here is machine-generated by a script in [`../src/`](../src/); none was edited by hand. **Every statistic in the report is recomputed from these files** by an `analyze_*.py` script, so any number in the writeup can be traced back to per-patient rows.

## Standard schema

Most files carry one row per (patient, region) on the held-out validation split:

| Column | Meaning |
|---|---|
| `patient_id` | e.g. `BraTS20_Training_117` |
| `region` | `ET` (enhancing tumor), `TC` (tumor core), `WT` (whole tumor) |
| `size_bin` | `small` / `medium` / `large`, per-region terciles of **true native-resolution** volume |
| `true_volume_mm3` | Lesion volume in mm³ at native resolution, not on the resampled grid |
| `dice`, `iou` | Overlap against ground truth |

Patients whose region volume is 0 are omitted (27 of 369 have no enhancing tumor), which is why ET files have fewer rows than TC/WT.

## Naming convention

`<experiment>_localization_scores.csv` is the seed-0 run. Seeds 1 and 2 append `_seed1` / `_seed2` — either before `_localization_scores` (for ablations and RQ7) or after (for RQ1, which was written earlier under a different convention). `analyze_seed_replication.py` and `analyze_rq7_multiseed.py` encode both conventions.

## Files

| File(s) | From | Contents |
|---|---|---|
| `rq1_localization_scores*.csv` | `evaluate_rq1.py` | The core baseline, three seeds. Baseline arm for all 171 paired tests. |
| `chance_baseline_scores.csv` | `compute_chance_baseline.py` | Random-heatmap control through the identical Otsu+Dice pipeline. |
| `rq2_*`, `rq4_*`, `rq5_*`, `rq6_*` | `evaluate_rq{2,4,5,6}.py` | The four retrained ablations, three seeds each. |
| `rq3_localization_scores.csv` | `evaluate_rq3_multiscale.py` | Naive multi-scale ensemble. |
| `rq3b_scale16only_scores.csv` | `evaluate_rq3b_scale16_only.py` | The 16³ window in isolation. |
| `rq3c_window{6,8,12}_scores.csv` | `evaluate_window_sweep.py` | The window-size curve. |
| `rq6_single_scale_oracle_scores.csv` | `evaluate_rq6_single_scale.py` | RQ6 mechanism-isolation oracle. |
| `rq7_*` (4 conditions × 3 seeds) | `evaluate_rq7.py` | Text-encoder ablations: BERT-base, random-init BERT, random orthonormal, random-at-PubMedBERT-geometry. |
| `rq8_compositionality_scores.csv` | `evaluate_rq8_compositionality.py` | Five probe conditions in one file, distinguished by a `condition` column. Adds `heatmap_spearman_vs_original` and `proj_cosine_vs_original`. |
| `rq11_threshold_confound_scores.csv` | `evaluate_rq11_threshold_confound.py` | Five binarization rules per patient (`threshold_method` column) plus predicted-volume and pointing-game columns. |
| `rq12_grounding_window{W}_stride{S}_scores.csv` | `evaluate_grounding_sweep.py` | As RQ11 but across the window sweep, with tie-aware pointing columns (`peak_tie_count`, `centroid_hit`, `any_tied_hit`). **Stride is in the filename deliberately**: the original sweep switched from 50%-overlap to non-overlapping tiling partway down, so (window, stride) are distinct conditions and a window-only name would silently overwrite one with the other. Conditions: 32/16, 16/8, 12/6, 8/4, 8/8, 6/6. |
| `pprime_supervised_scores.csv` | `evaluate_pprime_supervised.py` | The supervised P′ reference, same schema, same metric. |
| `full_family_statistics.csv` | `analyze_full_family.py` | **Derived, not raw**: all 171 paired tests with raw p, BH q-values under both correction schemes, effect sizes and bootstrap CIs. |

## Reading notes

- Files with a `threshold_method` or `condition` column hold several arms stacked; filter before pairing.
- `rq12_grounding_window32_stride16_scores.csv` reproduces `rq11_threshold_confound_scores.csv` on 212 of 213 patients bit-for-bit; the one exception differs by 5×10⁻⁴ Dice from a tie in Otsu's 256-bin histogram. This is the correctness gate on the RQ12 generalization.
- Absolute Dice in Otsu-thresholded files is a lower bound set jointly by the model and the binarizer — see Section 6.3 and 7.11 of the report before comparing across experiments.
